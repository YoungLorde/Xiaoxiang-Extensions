# ✨ Xiaoxiang Config Extension ✨

### *Your Dao. Your Rules.* ⚔️🌙

**📥 Download on CurseForge → https://www.curseforge.com/minecraft/mc-mods/xiaoxiang-config-extension**

---

A companion mod for **Xiaoxiang Cultivation World** that turns its hardcoded
values into real, editable settings - sixteen hundred of them - wrapped in a
purpose-built in-game config screen. And one screen for the whole pack: any
mod that has settings shows up on it, arranged and explained, Mekanism's nine
hundred among them.

Realm power curves · Spell damage · Alchemy timings · Sect economies · NPC
behaviour · Tribulation difficulty · Talismans · Equipment sets · Cultivation
fruit · Bosses · Identities · Inventory · HUD.

## What it does

- **1,625 settings** across 23 single-subject tabs and 107 sub-tabs
- **Every realm in true breakthrough order**, on every page, one group per realm
- **52 visual themes**, each with its own slow, continuous background animation
- Live search, favourites, undo/redo, per-world overrides, modpack presets
- Written descriptions on every tab, sub-tab and setting - never a raw key
- Every other mod's settings on the same screen, arranged by subject
- Accessibility: text scaling, high- and low-contrast themes, and a Reduce
  Motion option that freezes animation rather than merely slowing it

## How it works

**No file belonging to Xiaoxiang Cultivation World is ever modified.** Every
override is applied at runtime, and each category has its own switch - turn one
off and that system falls straight back to the base mod's own values.

Every default this mod ships is the base mod's own value. It invents no numbers
and imposes no balance; it is a tool for setting *yours*.

## Requirements

- Minecraft **1.20.1**
- Forge **47.x**
- **Xiaoxiang Cultivation World** - required
- *(optional)* **Configured** - adds the in-game button that opens the config
  screen from the Mods menu. Without it you can still edit the config files directly
